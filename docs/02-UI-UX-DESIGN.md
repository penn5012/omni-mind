## 一、全局视觉规范与 Design Tokens（严禁硬编码裸色值）

### 1. 色彩系统 (`AppColors`)

| Token 名称 | Hex 色值 | 适用场景 | Flutter / React 语义角色 |
| :--- | :--- | :--- | :--- |
| `bgPrimary` | `#0B0F17` | App 主工作台底层背景 | 全局 Scaffold / Body 背景 |
| `bgSurface` | `#161C28` | AI 消息容器、动态卡片背景、底部输入舱 | Card / BottomSheet 基础表面 |
| `bgElevated` | `#1E2638` | 思考链折叠框、代码块、悬停/高亮二级表面 | 二级嵌套卡片容器 |
| `borderSubtle` | `#2A344B` | 卡片描边、分割线 | `1px solid` 柔和边框 |
| `accentPrimary` | `#6366F1` | 品牌主色（Indigo 电光紫蓝）、用户气泡、主按钮 | Primary Action / AI 核心标识 |
| `accentCyan` | `#06B6D4` | RAG 引用角标 `[1]`、思考流光动画、向量相似度标签 | AI 检索与知识溯源高亮 |
| `statusSuccess` | `#10B981` | 工具已执行、日历已写入、服务器 Online 状态点 | 审批通过 / 写入成功态 |
| `statusWarning` | `#F59E0B` | Human-in-the-Loop 工具审批拦截边框与徽章 | 敏感操作挂起等待确认态 |
| `statusError` | `#EF4444` | 模型熔断报错、日程冲突提示、拒绝执行按钮 | 异常拦截与错误重试态 |
| `textPrimary` | `#F8FAFC` | 正文主标题、核心数字 | 高对比度主文字 |
| `textSecondary` | `#94A3B8` | 思考链文字、卡片副标题、时间戳 | 次级辅助信息 |
| `textMuted` | `#64748B` | 输入框 Placeholder、底部 `TTFT / Token` 可观测性微标 | 弱提示信息 |

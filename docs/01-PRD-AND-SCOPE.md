# 01. OmniMind 产品需求规格说明书 (PRD & Scope)

> **产品名称**：OmniMind（智脑随身助手 · 全模态端云协同个人效率 Agent）
> **产品核心理念**：**单一极简工作台 + 纵深 AI 工程链路**。拒绝繁琐的传统 CRUD 多级菜单，通过「随手拍/说 ➔ 智能提取与记忆归档 (RAG) ➔ 动态原生卡片交互 (Generative UI) ➔ 端云协同自动执行 (Agent & MCP)」解决个人碎片化信息处理与行动落地。

---

## 一、核心功能矩阵与 AI 技能映射

| 模块 ID | 功能模块名称 | 核心用户场景与功能明细 | 对应实战的 AI 工程师核心技能 |
| :--- | :--- | :--- | :--- |
| **F-01** | **全模态随手采集舱** | 1. 支持纯文本、HTML5 相机拍照/相册选图（会议白板、消费小票、报错截图、纸质文档）、Web Speech 语音输入。<br>2. 浏览器端侧自动完成 Canvas 图片压缩与敏感信息（手机号/身份证号）本地识别掩码脱敏。 | 多模态输入编排 (Multimodal Prompting)、前端 Canvas 预处理、端云隐私边界设计 |
| **F-02** | **多通道流式推理与 Generative UI 卡片流** | 1. 实时展示可折叠的 **`Thinking` 思考过程链**。<br>2. 文本流式打字机输出，支持随时手动中断（Abort）。<br>3. 根据意图自动下发并渲染 **4 类原生动态交互卡片**（日程待办卡、消费记账卡、工具审批卡、开销统计图表卡）。<br>4. 消息底部实时展示开发者可观测微标（`TTFT`、`Tokens`、`Cost`、`Model`）。 | 自定义多通道 SSE 流式协议、Zod / JSON Schema 强类型结构化输出、Generative UI 客户端动态组件映射 |
| **F-03** | **个人记忆库与精准溯源问答 (Pocket RAG)** | 1. 随手拍/说的图片与笔记自动提取高密度语义描述，经递归切片与 Embedding 存入向量库。<br>2. 询问历史信息（如“我上个月拍的体检单核心指标是什么？”）时，启用「全文 + 向量」混合检索与 Rerank 重排。<br>3. 回答中内嵌 **`[1][2]` 可点击引用角标**，点击滑出底部抽屉展示**原图缩略图 + 高亮原文段落 + 匹配得分**。 | 文档解析、Chunking 切片策略、Embedding 向量化、`pgvector`、Query 改写、Hybrid Search (RRF)、Rerank 重排、防幻觉引用溯源 |
| **F-04** | **端云协同 Agent 与 MCP 工具生态** | 1. 云端 Agent 通过 **MCP (Model Context Protocol)** 挂载扩展工具（网页正文抓取、实时天气/汇率、记忆库检索）。<br>2. 支持下发**客户端本地 Tool 指令**（调用手机系统日历创建日程、创建系统提醒、写入剪贴板）。<br>3. **人在回路 (Human-in-the-Loop)**：所有写操作强制流式挂起，弹出审批卡片，用户点击「批准」后方可执行并回传结果继续推理。 | LangGraph.js 状态机编排、MCP Server/Client 开发、端云双向 Tool Call、Human-in-the-Loop 安全护栏 |
| **F-05** | **多模型容灾网关与 LLMOps 评测体系** | 1. 顶部支持一键切换主模型（Gemini 2.5 Flash / Pro、DeepSeek-V3、Qwen-Max）；主模型超时 5s 自动无缝 Fallback 至备用模型。<br>2. 全链路接入 **Langfuse** 追踪 Trace 树与耗时分布。<br>3. 内置 40 条黄金测试问答集（Golden Dataset）与自动化跑批评测脚本。 | 多模型路由网关、容灾降级 (Fallback)、Langfuse 可观测性、LLM-as-a-Judge 自动化 Eval 评测 |

## 二、版本需求边界界定（遵循 App 交付工作流规范）

### 1. 首版 MVP（`v0.1`）必须交付范围（In-Scope Goals）
- 完成 TypeScript (`Hono` + `@google/genai`) BFF 后端服务，提供 `/api/chat/stream` 多通道 SSE 接口与 `/api/health` 健康检查接口；
- 实现后端多模型路由层（Gemini 主模型 + OpenAI 兼容备用模型自动 Fallback）；
- 完成 React + Ant Design 移动 H5 端（`apps/mobile-h5`）及 PC Web 控制台（`apps/web-console`）主工作台 UI，支持文本 + 拍照/选图输入；
- 跑通 `thinking`（思考态）➔ `text_delta`（流式正文）➔ `ui_card`（**日程待办卡 `schedule_card`** 与 **消费记账卡 `expense_card`**）渲染闭环；
- 支持流式生成中途点击「停止」立即中断请求（`AbortController`）。

### 2. 明确不做的边界（Non-Goals）
- **不做复杂账号与社交系统**：不做手机号短信登录、第三方 OAuth、好友分享或社区广场（采用单机 Device UUID / 本地配置即可）；
- **不做传统多级 CRUD 报表页面**：不开发独立的传统记账多级分类管理页或复杂日历月视图（所有交互收敛在对话流动态卡片与系统原生应用跳转中）；
- **不做重型长篇 PDF 排版阅读器**：移动端 RAG 聚焦于个人碎片化视觉/语音/笔记记忆（1~5 页以内文档、截图、票据、白板），不追求在手机小屏上渲染几百页的 PDF 阅读器。

## 三、阻断级核心冒烟测试场景（Smoke Testing Gate 100% 必过项）

每次版本提测与归档前，必须 100% 通过以下 5 个阻断级冒烟用例：

| 用例编号 | 用例名称 | 前置条件与操作步骤 | 预期通过标准（100% 达标线） |
| :--- | :--- | :--- | :--- |
| **SMK-01** | **冷启动与多分辨率防溢出检查** | 启动 H5 工作台，分别在 360×640（小屏）与 393×852（主流屏）移动视口下渲染包含长文本与动态卡片的会话列表 | 首屏加载耗时 < 2s；页面 **0 横向滚动溢出**、控制台无报错；顶部后端连接状态灯显示绿色 Online |
| **SMK-02** | **流式问答与中途手动中断 (Abort)** | 输入长问题发送，观察思考框与打字机流式输出；在输出进行到一半时点击底部「停止生成」按钮 | 首字延迟 TTFT 显示正常；点击停止后 **200ms 内流式吐字立即终止**，连接正常释放，界面无异常弹窗或崩溃 |
| **SMK-03** | **多模态识图与 Generative UI 卡片渲染** | 选择一张包含会议时间/地点的白板照片或消费小票发送，附带指令“帮我提取一下” | 后端正确识别图片内容并通过 SSE 下发 `ui_card` 事件；客户端准确渲染出原生**日程卡片**或**记账卡片**，字段无缺失 |
| **SMK-04** | **RAG 记忆检索与角标溯源抽屉 (v0.2+)** | 提问已入库的历史笔记内容，待回答生成后点击正文中的 `[1]` 引用角标 | 底部平滑弹出半屏溯源抽屉（BottomSheet），准确展示召回的**原始图片缩略图、匹配高亮文本片段及相似度分数** |
| **SMK-05** | **端云工具审批与异常容灾降级 (v0.3+)** | 1. 要求 AI “把该日程写入我手机日历”；<br>2. 模拟主模型 API Key 失效或超时 | 1. 弹出 `tool_approval_card`，点击“批准”后成功写入系统日历；<br>2. 主模型异常时自动 Fallback 至备用模型或展示「一键重试」卡片，**App 零 Crash、零白屏** |

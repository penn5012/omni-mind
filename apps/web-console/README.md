# `@omnimind/web-console` — Next.js Generative UI 工作台与 RAG 评测看板

- **技术栈**：React 19 + TypeScript + Ant Design 5.x (`antd` + `@ant-design/icons` + `ConfigProvider` Token 主题定制) + Vite
- **核心职责**：
  1. Web 端多模态流式问答工作台与 Generative UI 组件渲染
  2. 个人记忆库文档批量管理、切片预览与检索调试台
  3. RAG 自动化 Eval 跑分对比与 Langfuse 延迟/成本指标可视化看板
